# Pacifyre IWM III / FPW – kalkulačka spotřeby pásky

Čtyřjazyčná responzivní kalkulačka spotřeby protipožárních pásek.

## Spuštění

Otevřete `index.html` přímo v prohlížeči. Kalkulačka funguje offline.

## GitHub Pages

1. Nahrajte všechny čtyři soubory do kořenového adresáře repozitáře `wrap-paska` na větev `main`.
2. V Settings → Pages nastavte `Deploy from a branch`, větev `main`, složku `/(root)` a uložte.
3. Po publikaci bude stránka na `https://dronepilotjs.github.io/wrap-paska/`.

Technické podklady: ETA-18/0918 (IWM III), ETA-22/0022 (FPW). Před závazným návrhem ověřte systémové podmínky ETA.
